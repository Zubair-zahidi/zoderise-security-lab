# Security and Linux learning toolkit

This is a learning path, not a claim of professional mastery. Practice only in systems you own or labs with explicit authorization.

| Area | Tools or concepts | Evidence to produce |
| --- | --- | --- |
| Linux | Shell navigation, file permissions, processes, services, and logs | A documented local configuration review and retest. |
| Network analysis | [Wireshark documentation](https://www.wireshark.org/docs/) | A sanitized explanation of your own lab traffic. |
| Authorized network discovery | [Official Nmap guide](https://nmap.org/book/) | A small owned-lab inventory, with scope and limitations. |
| Web security | [PortSwigger Web Security Academy](https://portswigger.net/web-security) and [ZAP documentation](https://www.zaproxy.org/docs/) | A lab finding explaining cause, evidence, remediation, and retest. |
| Defensive automation | Python, Git, integrity baselines, and structured reports | A tested tool and an honest explanation of what it does. |

Start with networking and operating-system fundamentals. Add tools as you can explain their output, false positives, and limits. Keep real credentials and private captures out of Git repositories.
